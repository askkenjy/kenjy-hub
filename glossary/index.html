Core AI words

AI

Artificial intelligence — software that can generate text, images, audio, or decisions from patterns it learned. Treat it as a helper, not a magic paycheck.

LLM

Large language model — the kind of AI that reads and writes language (chat answers, scripts, emails). ChatGPT, Claude, and Grok are LLM products.

Model

The trained AI “brain” behind a product. Different models feel different — some shorter, some deeper, some better at code or images.

Token

A chunk of text the model counts (part of a word, a word, or punctuation). Limits and pricing often run on tokens, not “pages.”

Training data

The examples the model learned from before you met it. It shapes what the model knows — and what it might invent.

Context window

How much of the conversation the model can “see” at once. Long chats can push early details out of memory — start fresh or summarize when needed.

Temperature

A creativity dial. Lower = more predictable. Higher = more variety (and sometimes more nonsense). For money tasks, start lower.

Hallucination

When the AI sounds confident but is wrong or made something up. Always check facts before you post, sell, or send.

Hallucination check

Your habit of verifying AI output — sources, numbers, names, links — before it represents your brand.

Multimodal

AI that works with more than one kind of input or output — text plus images, audio, or files in the same chat.

Embedding / vector search

A way to turn meaning into numbers so a tool can find “similar” ideas, docs, or FAQs — light concept: search by meaning, not only exact keywords.

Fine-tuning

Extra training on your examples so a model leans toward your style or niche. Most beginners start with good prompts before fine-tuning.

Guardrails

Rules and filters that keep AI outputs safer and on-brand — what it should refuse, how it should talk, what it must not invent.

Talking to AI

Prompt

What you type or say to the AI — your instruction, question, or brief. Clear prompts beat clever ones.

Prompt engineering

The skill of writing better prompts on purpose — role, goal, format, examples — so you get usable drafts faster.

System prompt

Hidden or pinned instructions that set the AI’s job and rules for a whole chat or custom bot (tone, audience, do/don’t).

Output

What the AI returns — the draft, answer, image, or plan. You edit it; you own what you publish.

Chatbot

An AI you talk to in a chat box. Great for drafting and Q&A; still needs your judgment.

ChatGPT

OpenAI’s popular chat product powered by LLM models. One of several tools you can use — not the only path.

Claude

Anthropic’s chat / assistant product. Another LLM option beginners can try for writing and thinking work.

Grok

xAI’s assistant. Another model choice in the same category as other chat LLMs.

Custom GPT / Project

A saved setup with your instructions, files, or tools so you do not re-explain your brand every time.

Building with AI

Agent

An AI setup that can follow multi-step work toward a goal (draft → check → organize), not only one chat reply. Still needs your oversight.

Workflow

A repeatable sequence of steps — human and/or AI — that turns inputs into a finished deliverable (caption pack, email, offer outline).

Artifact

A finished piece you can keep or ship — a doc, script, checklist, or asset — not just chat scroll.

API

A way for apps to talk to each other with rules. You use APIs when tools connect behind the scenes; beginners can ignore the code until they need it.

Plugin

An add-on that gives a chat tool extra abilities (search, calc, shop tools). Names vary by product.

Connector

A bridge that links your AI assistant to another app or data source so it can read or act with permission — not a free pass to skip your judgment.
